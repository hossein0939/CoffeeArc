# نصب کافه آرک روی هاست سی‌پنل

سیستم منوی قابل‌اسکن + سفارش مشتری/مسئول + پرداخت زرین‌پال (PHP 8 + MySQL).

## پیش‌نیاز
- PHP 8.0+ (افزونه‌ها: `pdo_mysql`, `curl`, `mbstring`, `fileinfo`, `json`)
- MySQL / MariaDB
- دسترسی به File Manager یا FTP

## نصب سریع (۳ مرحله)

### ۱) آپلود فایل‌ها
1. کل محتویات پروژه را آپلود کنید (یا فایل ZIP را Extract کنید).
2. **Document Root** دامنه/ساب‌دامین را روی پوشه `public` بگذارید.
   - اگر فقط `public_html` دارید: محتویات داخل `public` را در `public_html` بریزید و پوشه‌های `app`, `views`, `sql`, `storage` را یک سطح بالاتر از `public_html` قرار دهید، سپس در `public_html/index.php` مسیر bootstrap را در صورت نیاز اصلاح کنید.
   - ساده‌ترین حالت: ساب‌دامین با ریشه روی `/home/USER/coffeearc/public`

### ۲) دیتابیس
در سی‌پنل یک دیتابیس MySQL و کاربر بسازید و کاربر را به دیتابیس با دسترسی کامل وصل کنید.

### ۳) ویزارد نصب
1. سایت را باز کنید → صفحه نصب ظاهر می‌شود.
2. اطلاعات دیتابیس، آدرس سایت (`https://yourdomain.com`) و رمز ادمین را وارد کنید.
3. بعد از نصب به `/admin/login` بروید.

ورود پیش‌فرض فقط همان چیزی است که در نصب وارد کرده‌اید.

## تنظیمات مهم بعد از نصب
- **تنظیمات → زرین‌پال:** Merchant ID واقعی را بگذارید. مقدار `TEST` درگاه آزمایشی داخلی است.
- **سوئیچ قابلیت‌ها:** سفارش آنلاین، پرداخت آنلاین، پرداخت در کافه، الزام میز، QR میز، سفارشی‌سازی، تخفیف، POS و … را روشن/خاموش کنید.
- از بخش **میزها** یا **تنظیمات** QR هر میز را چاپ کنید.

## مسیرهای اصلی
| مسیر | کاربرد |
|------|--------|
| `/m` | منوی مشتری |
| `/m?t=03&token=...` | منوی میز خاص (از QR) |
| `/admin` | پنل مدیر / سفارش‌های زنده |
| `/admin/pos` | ثبت سفارش مسئول |
| `/admin/settings` | فیچرفلگ و زرین‌پال |

## امنیت
- بعد از نصب موفق، فایل `storage/installed.lock` ساخته می‌شود و ویزارد قفل می‌شود.
- پوشه `storage` و `.env` نباید از وب قابل دسترس باشند (با Document Root روی `public` درست است).
- پوشه `public/uploads` باید قابل نوشتن باشد (chmod 755 یا 775).

## عیب‌یابی
- صفحه سفید: `APP_DEBUG=true` را موقتاً در `.env` بگذارید.
- خطای دیتابیس: اطلاعات `.env` را با سی‌پنل چک کنید.
- آپلود عکس کار نمی‌کند: دسترسی نوشتن روی `public/uploads`.
